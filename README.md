# shazam
Shazam a back-safe, 4-day strength and hypertrophy program built around a bigger bench, broader upper-body growth, controlled leg work, microplate progression, and recovery decisions for lifters who can’t train like reckless 25-year-olds anymore.

The app reads workouts from Hevy, applies the program's progression rules, and sends the next targets back to the Hevy routines.

- `program.js`: the routines and how each exercise progresses
- `rules.js`: the progression rules (tests in `tests/`, run `npm test`)
- `hevy.js`, `app.js`, `index.html`: Hevy connection and screens
